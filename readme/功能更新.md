## 2026-06-23 - 修复已点火但油门为0的发动机误判问题

### 修复
- 修复 `LaunchSafetyChecker.cs` 中发动机状态检测逻辑
  - 根因：`IsAnyEngineRunning()` 仅判断 `finalThrust > 0.01f`，当玩家手动点火发动机但保持油门为0时，当前推力为0，被误判为未启动。
  - 修复方式：增加 `ModuleEngines.EngineIgnited` 判断，只要发动机可运行且已被点火（即使油门为0），即视为已启动。
  - 涉及文件：`LaunchSafetyChecker.cs`

### 变更
- 发动机已启动（`EngineAlreadyRunning = true`）时，倒计时期间自动保持0油门、音频结束后加满油门，防止提前起飞。
- "先启动发动机再分离"UI选项仅控制是否执行后续放行分级：
  - **勾选且发动机已点火**：音频结束后满油门 → 按 `singleStageDelay`/`multiStageDelay` 延迟后执行一次分级（放行）。
  - **勾选且发动机未点火**：保持原有"先启动发动机再分离"行为，分级点火 → 延迟 → 第二次分级放行。
  - **未勾选且发动机已点火**：只加满油门，不执行自动分级，由玩家手动控制。
  - **未勾选且发动机未点火**：执行普通发射流程，满油门 → 分级。
- 涉及文件：`CountdownController.cs`、`LaunchSafetyChecker.cs`（注释说明）

    - 注入 Localization 实例
- 发射前安全检查（v0.2.3 规划内容）
  - 新增 `LaunchSafetyChecker.cs` 安全检查器
    - 检查是否在发射台（高度 < 100m 且速度接近 0）
    - 检查是否已有正在进行的倒计时
    - 检查飞船电量：当前电量小于总电量的 1/20 时拒绝发射
    - 检查芯一级发动机是否已启动
    - `SafetyCheckResult` 记录 `LowElectricCharge` 标志，用于SAS失败时区分MJ控制和停电
  - 修改 `CountdownController.cs`
    - 根据安全检查结果决定是否采用"先点火后放行"策略
    - 发动机已启动时：倒计时期间保持 0 油门，音频结束后只加满油门，不执行自动分级
    - 发射前准备序列中尝试开启SAS最多3次：
      - 3次后仍失败且电量正常：判断为MJ控制，继续正常执行分级
      - 3次后仍失败且电量低：判断为停电，中止发射序列
    - 新增 `OnSafetyCheckFailed` 事件，确保内部安全检查失败时也能通知UI显示警告
  - 修改 `LaunchSequence.cs`
    - 新增 `SetThrottle(float)` 通用方法
    - 新增 `SetZeroThrottle()` 快捷方法
    - 修改油门保持机制，支持任意目标油门值
  - 修改 `CountdownMenu.cs`
    - 点击 Launch 时执行安全检查
    - 检查未通过时在菜单内显示警告和"强制发射"复选框
    - 勾选强制发射后可跳过检查启动倒计时
