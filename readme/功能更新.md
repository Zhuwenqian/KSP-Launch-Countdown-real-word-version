## 2026-07-04 - 添加对外 API 接口供其他模组调用

### 新增
- 新增对外接口类 `src/KSPLaunchCountdown/CountdownAPI.cs`
  - 单例 `CountdownAPI.Instance`，其他模组可通过反射访问
  - `SelectPreset(string presetName)`：按名称选择倒计时语音包预设
  - `StartCountdown()`：使用当前已选预设启动倒计时
  - `StartCountdown(string presetName)`：选择指定预设并立即启动倒计时
  - `CancelCountdown()`：取消正在进行的倒计时
  - `GetAvailablePresets()`：获取所有可用预设名称列表
  - `GetCurrentPresetName()`：获取当前选中预设名称
  - `IsCountingDown()`：查询是否正在倒计时
  - `StartEngineBeforeSeparation` 属性：外部模组启动时是否启用"先启动发动机再分离"，默认 false
  - 实例事件：`OnPresetSelected`、`OnCountdownStarted`、`OnCountdownFinished`、`OnSafetyCheckFailed`
  - KSP GameEvents 广播：`KSPLaunchCountdownPresetSelected`、`KSPLaunchCountdownStarted`、`KSPLaunchCountdownFinished`

### 变更
- `KSPLaunchCountdownMod.cs`

  - `Initialize` 增加可选 `CountdownAPI` 参数

  - 头部注释增加对外接口说明，提示外部模组通过 `CountdownAPI` 调用

## 2026-06-23 - 修复已点火但油门为0的发动机误判问题

### 修复
- 修复 `LaunchSafetyChecker.cs` 中发动机状态检测逻辑
  - 根因：`IsAnyEngineRunning()` 仅判断 `finalThrust > 0.01f`，当玩家手动点火发动机但保持油门为0时，当前推力为0，被误判为未启动。
  - 修复方式：增加 `ModuleEngines.EngineIgnited` 判断，只要发动机可运行且已被点火（即使油门为0），即视为已启动。
  - 涉及文件：`LaunchSafetyChecker.cs`

### 变更
- 发动机已启动（`EngineAlreadyRunning = true`）时，倒计时期间自动保持0油门、音频结束后加满油门，防止提前起飞。
- "先启动发动机再分离"UI选项仅控制是否执行后续放行分级：
  - **勾选且发动机已点火**：音频结束后满油门 → 按 `singleStageDelay`/`multiStageDelay` 延迟后执行一次分级（放行）。
  - **勾选且发动机未点火**：保持原有"先启动发动机再分离"行为，分级点火 → 延迟 → 第二次分级放行。
  - **未勾选且发动机已点火**：只加满油门，不执行自动分级，由玩家手动控制。
  - **未勾选且发动机未点火**：执行普通发射流程，满油门 → 分级。
- 涉及文件：`CountdownController.cs`、`LaunchSafetyChecker.cs`（注释说明）
